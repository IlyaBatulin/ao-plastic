## Структура данных

### Таблица extrusion_products

| Поле | Тип | Описание |
|------|-----|----------|
| id | serial | ID записи |
| type | text | Тип изделия (Сепаратор, Трубка, и т.д.) |
| subtype | text | Подтип (защитная, перфорированная) |
| name | text | Наименование товара |
| size_raw | text | Габаритные размеры как есть |
| size_a_mm | numeric | Первая размерность (парсится) |
| size_b_mm | numeric | Вторая размерность (парсится) |
| size_note | text | Примечания к размерам |
| code | text | Шифр изделия |
| length_raw | text | Длина изделия как есть |
| length_kind | text | coil или fixed |
| length_mm | numeric | Длина в мм (для fixed) |
| length_tolerance_raw | text | Допуск (±5, +10 и т.д.) |
| source_no | int | № пп из документа |
| is_active | boolean | Активность записи |
| created_at | timestamptz | Дата создания |

## Примеры SQL запросов

### Все трубки
```sql
SELECT * FROM extrusion_products WHERE type = 'Трубка';
```

### Только в бухтах
```sql
SELECT * FROM extrusion_products WHERE length_kind = 'coil';
```

### Поиск по шифру
```sql
SELECT * FROM extrusion_products WHERE code ILIKE '%Ф-%';
```

### Защитные трубки
```sql
SELECT * FROM extrusion_products 
WHERE type = 'Трубка' AND subtype = 'защитная';
```

### С фиксированной длиной 600-700 мм
```sql
SELECT * FROM extrusion_products 
WHERE length_kind = 'fixed' 
  AND length_mm BETWEEN 600 AND 700
ORDER BY length_mm;
```

### Ошибка "relation does not exist"
**Решение:** Выполните все три миграции последовательно

### Не работают фильтры
**Решение:** Проверьте консоль браузера на ошибки JavaScript
