# 🚀 Быстрый запуск интеграции с HeadHunter

## Шаг 1: Найдите ID вашей компании

Выполните команду (замените "АО Пластик" на название вашей компании):

```bash
python scripts/find-hh-employer.py "АО Пластик"
```

Или узнайте ID из URL страницы компании на hh.ru:
```
https://hh.ru/employer/123456
                      ^^^^^^ это ID
```

## Шаг 2: Вставьте ID в код

Откройте файл: `app/api/hh-vacancies/route.ts`

Измените строку 4:
```typescript
const EMPLOYER_ID = "541232" // 👈 Вставьте сюда ID вашей компании
```

## Шаг 3: Запустите сайт

```bash
npm run dev
```

## Шаг 4: Проверьте

Откройте: http://localhost:3000/about/vacancies

Переключитесь на вкладку **"Вакансии на HeadHunter"**

---

## ✅ Готово!

Теперь на вашем сайте:
- ✅ Отображаются актуальные вакансии с HeadHunter
- ✅ Пользователи могут кликнуть "Откликнуться на HH.ru"
- ✅ Данные обновляются автоматически каждый час
- ✅ Вакансии показываются с зарплатой, адресом и требованиями
