# 🚨 БЫСТРОЕ РЕШЕНИЕ ОШИБКИ RLS

## Проблема

Вы видите ошибку типа:
```
new row violates row-level security policy for table "orders"
new row violates row-level security policy for table "audit_log"
```

Это означает, что таблицы уже существуют в вашей БД, но у них нет правильных политик RLS для публичной вставки.

## ✅ Решение (2 минуты)

**Примените ОДНУ миграцию в Supabase SQL Editor:**

1. Откройте [Supabase Dashboard](https://app.supabase.com) → ваш проект → **SQL Editor**
2. Создайте новый запрос (New Query)
3. Скопируйте содержимое файла `migrations/000_fix_rls_policies.sql`
4. Вставьте в редактор
5. Нажмите **Run** или `Ctrl+Enter`

**Готово!** Теперь можно оформлять заказы.

---

## Что делает эта миграция?

- ✅ Включает RLS на всех таблицах (`orders`, `order_items`, `audit_log`, `customers`, `categories`, `products` и т.д.)
- ✅ Добавляет публичную политику для вставки в `orders` (чтобы сайт мог создавать заказы)
- ✅ Добавляет публичную политику для вставки в `order_items` (позиции корзины)
- ✅ Добавляет публичную политику для вставки в `audit_log` (триггеры пишут сюда)
- ✅ Добавляет политики для чтения категорий и товаров
- ✅ Создаёт функцию назначения менеджеров и триггер
- ✅ **БЕЗОПАСНА для повторного применения** — использует `IF EXISTS`, `OR REPLACE`
