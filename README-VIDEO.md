# Инструкция по добавлению видео на страницы категорий

## 📹 Требования к видео

### Размеры для компьютера (рекомендуемые)
- **Оптимально:** 1920x1080 (Full HD, соотношение 16:9)
- **Альтернатива:** 2560x1440 (2K, для высокого качества)
- **Минимум:** 1280x720 (HD, для экономии трафика)

### Технические характеристики
- **Формат:** MP4 (кодек H.264)
- **Размер файла:** до 10-20 МБ (для быстрой загрузки)
- **Длительность:** 30-60 секунд (для фонового видео)
- **Соотношение сторон:** 16:9 (идеально для всех устройств)

### ⚠️ Важно: Обрезка НЕ требуется!

**Не нужно физически обрезать видео для разных устройств!**

Код автоматически адаптирует видео через CSS:
- На мобильных: видео обрезается по центру (`object-fit: cover`)
- На планшетах/ноутбуках: адаптируется под размер экрана
- На компьютерах: показывается полностью

Одно видео будет работать на всех устройствах без создания разных версий.

## 📁 Размещение файлов

Поместите видеофайлы в папку `public/videos/`:

```
public/
  videos/
    polystyrene-category.mp4          # Для категории Полистирол
    polystyrene-psv-s.mp4            # Для подкатегории ПСВ-С
    polystyrene-psv-l.mp4            # Для подкатегории ПСВ-Л
    polystyrene-pse-1.mp4            # Для подкатегории ПСЭ-1
```

## 🔧 Настройка в коде

Видео настроены через конфигурационный файл `lib/video-config.ts`.

Чтобы добавить новое видео:
1. Поместите файл в `public/videos/`
2. Откройте `lib/video-config.ts`
3. Добавьте запись в объект `videoConfig`:

```typescript
export const videoConfig: Record<string, string> = {
  'category-id': '/videos/category-video.mp4',
  'category-id/subcategory-id': '/videos/subcategory-video.mp4',
  // ... ваши видео
}
```

## 🎬 Использование

Видео автоматически появится на:
- Странице категории: `/products/polystyrene` (вместо/вместе с изображением)
- Странице подкатегории: `/products/polystyrene/ps-psv-s` (в шапке с названием)

Если видео не указано, будет показано изображение (как было раньше).

## ✨ Особенности

- Автоматическое воспроизведение (с выключенным звуком)
- Зацикливание видео
- Адаптивное отображение на всех устройствах
- Оптимизированная загрузка (lazy loading для некритичных видео)
