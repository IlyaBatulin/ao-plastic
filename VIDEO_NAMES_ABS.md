# Названия видео файлов для АБС-пластиков

Поместите следующие видео файлы в папку `public/videos/`:

## Категория АБС-пластики (главная страница категории)
**Файл:** `abs-category.mp4`
**Путь:** `/videos/abs-category.mp4`
**Использование:** Hero section на странице `/products/abs`

## Подкатегории АБС

### 1. Литьевые марки
**Файл:** `abs-injection.mp4`
**Путь:** `/videos/abs-injection.mp4`
**Использование:** Hero section на странице `/products/abs/abs-injection`

### 2. Экструзионные марки
**Файл:** `abs-extrusion.mp4`
**Путь:** `/videos/abs-extrusion.mp4`
**Использование:** Hero section на странице `/products/abs/abs-extrusion`

### 3. Изготовление изделий из АБС пластика на заказ
**Файл:** `abs-custom.mp4`
**Путь:** `/videos/abs-custom.mp4`
**Использование:** Hero section на странице `/products/abs/abs-custom`

---

## Итого нужно 4 видео файла:

1. `abs-category.mp4` - для главной страницы категории АБС
2. `abs-injection.mp4` - для подкатегории "Литьевые марки"
3. `abs-extrusion.mp4` - для подкатегории "Экструзионные марки"
4. `abs-custom.mp4` - для подкатегории "Изготовление изделий на заказ"

Все файлы должны быть в формате MP4 и размещены в папке `public/videos/`
