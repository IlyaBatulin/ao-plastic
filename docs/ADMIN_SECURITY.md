# Защита админ-панели

## Переменные окружения

Добавьте в `.env.local`:

```env
# Обязательно: пароль для входа
ADMIN_PASSWORD=ваш_надёжный_пароль

# Рекомендуется: секрет для подписи сессии (если не задан — используется ADMIN_PASSWORD)
ADMIN_SESSION_SECRET=случайная_строка_32_символа

# Опционально: секретный путь к админке (например panel-a1b2c3d4)
# Если задан, /admin возвращает 404. Путь НЕ попадает в браузер — его нельзя найти в DevTools
ADMIN_PATH=panel-ваш_секретный_код
```

## Реализованные меры защиты

1. **Rate limiting** — после 5 неудачных попыток входа блокировка на 15 минут по IP
2. **Подписанная сессия** — вместо простого "authenticated" используется HMAC-подписанный токен с истечением через 4 часа
3. **Секретный путь** — при заданном `ADMIN_PATH` стандартный `/admin` возвращает 404
4. **HttpOnly cookie** — сессия недоступна из JavaScript
5. **Secure cookie** — в production передаётся только по HTTPS

## Рекомендации

- Используйте пароль не менее 12 символов
- Задайте уникальный `ADMIN_PATH` (например `panel-` + случайные 8 символов)
- Храните `.env.local` в безопасности, не коммитьте в git
