# 🔗 Инструкция по настройке интеграции с Bitrix24

## 🎯 Цель

Настроить автоматическую отправку данных о заказах в Bitrix24 через входящий вебхук.

## 📋 Пошаговая инструкция

### Шаг 1: Создание входящего вебхука в Bitrix24

1. Войдите в ваш Bitrix24
2. Откройте **Настройки** → **Разработчикам**
3. В разделе **Другое** выберите **Входящий вебхук**
4. Нажмите **"Добавить вебхук"**
5. Заполните параметры:
   - **Название**: "Заказы с сайта АО Пластик"
   - **Права**: 
     - ✅ `crm` — Работа с CRM
     - ✅ `user` — Информация о пользователях
   - **Пользователь**: Выберите администратора или ответственного за CRM
6. Нажмите **"Сохранить"**
7. Скопируйте URL вебхука (например: `https://your-domain.bitrix24.ru/rest/1/abc123def456/`)

### Шаг 2: Добавление URL в .env.local

```env
BITRIX_WEBHOOK_URL=https://your-domain.bitrix24.ru/rest/1/abc123def456/
```

### Шаг 3: Формат данных

Bitrix24 будет получать следующие данные:

```json
{
  "event": "order_created",
  "order_id": 123,
  "manager_id": 1,
  "customer_name": "Иван Иванов",
  "customer_phone": "+7 999 123-45-67",
  "customer_email": "ivan@example.com",
  "order_date": "2024-01-15T10:30:00Z",
  "items": [
    {"name": "ПСВ-С марка 1", "quantity": 10},
    {"name": "ПСВ-С марка 2", "quantity": 5}
  ]
}
```

## 🔧 Дальнейшая настройка

### Вариант A: Автоматическое создание сделок через Bitrix24

**Метод 1: Смарт-процессы (рекомендуется)**

1. В Bitrix24 создайте Смарт-процесс "Заказы с сайта"
2. Настройте автоматический триггер на входящий вебхук
3. Настройте поля:
   - `NAME` — название товара
   - `PRODUCTS` — список товаров
   - `CONTACT_NAME` — имя клиента
   - `PHONE` — телефон клиента
   - `EMAIL` — email клиента
   - `UF_ORDER_ID` — ID заказа (custom field)

**Метод 2: REST API скрипт**

Создайте PHP скрипт на Bitrix24 для обработки вебхука:

```php
<?php
// webhook-handler.php
require($_SERVER["DOCUMENT_ROOT"]."/bitrix/modules/main/include/prolog_before.php");

$data = json_decode(file_get_contents('php://input'), true);

if ($data['event'] === 'order_created') {
    // Создаем сделку
    $deal = new CIBlockElement;
    $arFields = [
        "NAME" => "Заказ #" . $data['order_id'],
        "PROPERTY_VALUES" => [
            "CUSTOMER_NAME" => $data['customer_name'],
            "CUSTOMER_PHONE" => $data['customer_phone'],
            "CUSTOMER_EMAIL" => $data['customer_email'],
            "ORDER_ID" => $data['order_id'],
        ]
    ];
    $deal->Add($arFields);
}
```

### Вариант B: Ручная обработка

Если создание сделок не требуется автоматически, данные просто отправляются в Bitrix24, и вы можете обработать их вручную через любой триггер или скрипт.

## ✅ Проверка работы

1. Откройте Bitrix24 → CRM → Сделки
2. Создайте тестовый заказ на сайте
3. Проверьте консоль сервера на наличие:
   ```
   [Bitrix24] Webhook configured: true
   [Bitrix24] Order sent successfully
   ```
4. Проверьте, что сделка создалась в Bitrix24

## 🐛 Отладка

Если данные не приходят в Bitrix24:

1. **Проверьте URL вебхука**:
   - Откройте URL в браузере
   - Должен вернутьсь JSON с методами API

2. **Проверьте логи**:
   - Смотрите консоль сервера
   - Ищите строки `[Bitrix24]`

3. **Проверьте права вебхука**:
   - Убедитесь что права `crm` включены
   - Проверьте что пользователь активен

4. **Тестовая отправка**:
   ```bash
   curl -X POST https://your-domain.bitrix24.ru/rest/1/webhook-code/ \
     -H "Content-Type: application/json" \
     -d '{"event":"order_created","order_id":999}'
   ```

## 📝 Примечания

- ⚠️ **Безопасность**: Храните URL вебхука в секрете
- 🔄 **Асинхронность**: Отправка в Bitrix24 не блокирует работу сайта
- 📊 **Логирование**: Все ошибки логируются в консоль
- 🎯 **Обработка**: Для автоматического создания сделок потребуется дополнительная настройка
