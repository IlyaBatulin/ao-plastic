# Примеры ID работодателей на HeadHunter

Для тестирования интеграции можете использовать эти ID:

## Крупные компании

- **Яндекс**: `1740` - много вакансий
- **Сбербанк**: `3529` - банковский сектор
- **Ozon**: `2180` - ритейл и IT
- **VK (ВКонтакте)**: `64174` - IT и маркетинг
- **Лаборатория Касперского**: `1057` - информационная безопасность
- **МТС**: `3776` - телеком
- **Т-Банк (Тинькофф)**: `78638` - финтех
- **Газпром**: `39305` - нефтегазовая отрасль

## Производственные компании

- **Сибур**: `906557` - нефтехимия
- **РУСАЛ**: `2867885` - металлургия
- **Ростех**: `1373124` - промышленность

## Как использовать для теста

1. Откройте `app/api/hh-vacancies/route.ts`
2. Временно замените ID на один из примеров выше:
   ```typescript
   const EMPLOYER_ID = "1740" // Яндекс для теста
   ```
3. Запустите `npm run dev`
4. Проверьте что вакансии загружаются
5. Верните свой ID компании

## Проверка вашего ID

Чтобы проверить что ваш ID работает:

```bash
# Получить информацию о компании
python scripts/find-hh-employer.py --id ВАШ_ID

# Или напрямую в браузере
https://api.hh.ru/employers/ВАШ_ID
https://api.hh.ru/vacancies?employer_id=ВАШ_ID
```
