# Интеграция вакансий с HeadHunter

## Что сделано

1. **API Route** `/api/hh-vacancies` - получает вакансии с HeadHunter API
2. **Компонент** `HHVacanciesClient` - отображает вакансии с HeadHunter
3. **Переключатель** между вакансиями с HH и внутренними вакансиями

## Как настроить

### 1. Найти ID вашей компании на HeadHunter

Есть несколько способов:

#### Способ 1: Из URL на сайте HH.ru
1. Зайдите на страницу вашей компании: `https://hh.ru/employer/YOUR_ID`
2. ID - это число в URL после `/employer/`

#### Способ 2: Через поиск по названию компании
```javascript
// Создайте файл scripts/find-hh-employer.js
const fetch = require('node-fetch');

async function findEmployer(companyName) {
  const response = await fetch(
    `https://api.hh.ru/employers?text=${encodeURIComponent(companyName)}`,
    {
      headers: {
        'User-Agent': 'AOPlastic/1.0 (ao-plastic-website)'
      }
    }
  );
  
  const data = await response.json();
  
  console.log('Найденные компании:');
  data.items.forEach(company => {
    console.log(`ID: ${company.id} | Название: ${company.name}`);
    console.log(`Вакансии: ${company.open_vacancies}`);
    console.log(`URL: ${company.alternate_url}`);
    console.log('---');
  });
}

// Замените на название вашей компании
findEmployer('АО Пластик');
```

Запустите:
```bash
node scripts/find-hh-employer.js
```

#### Способ 3: Прямой поиск в браузере
1. Откройте: https://hh.ru/search/employer?text=АО+Пластик
2. Найдите свою компанию и скопируйте ID из URL

### 2. Вставить ID в код

Откройте файл `app/api/hh-vacancies/route.ts` и замените:

```typescript
const EMPLOYER_ID = "541232" // Замените на ID вашей компании
```

### 3. Проверить работу

1. Запустите сервер разработки:
```bash
npm run dev
```

2. Откройте: http://localhost:3000/about/vacancies

3. Переключитесь на вкладку "Вакансии на HeadHunter"

## Функциональность

### Что показывается для каждой вакансии:
- ✅ Название вакансии
- ✅ Логотип компании (если есть)
- ✅ Краткое описание (требования и обязанности)
- ✅ Ключевые навыки
- ✅ Город и метро
- ✅ Зарплата (если указана)
- ✅ График работы
- ✅ Требуемый опыт
- ✅ Адрес
- ✅ Дата публикации
- ✅ Кнопка "Откликнуться" - ведет на страницу отклика на HH.ru
- ✅ Кнопка "Подробнее" - ведет на полную страницу вакансии

### Особенности:
- Данные кэшируются на 1 час
- Пагинация (по 20 вакансий на страницу)
- Автоматическая загрузка детальной информации для каждой вакансии
- Респонсивный дизайн
- Обработка ошибок

## Ограничения API HeadHunter

- **Без авторизации**: можно только **читать** вакансии
- **Для откликов**: пользователи переходят на сайт HH.ru
- **Лимит**: 2000 запросов в час
- **Пагинация**: максимум 100 страниц (2000 вакансий)

## Если нужна автоматическая подача заявок

Для этого потребуется:
1. Регистрация приложения на HH.ru
2. OAuth 2.0 авторизация
3. Access token для каждого пользователя
4. Использование API endpoint `/negotiations`

Подробнее: https://github.com/hhru/api/blob/master/docs/negotiations.md

## Примечания

- Данные обновляются автоматически каждый час
- Если вакансий нет, показывается соответствующее сообщение
- Все ссылки открываются в новой вкладке
- Поддерживаются все валюты HH (RUB, USD, EUR, KZT, etc.)
