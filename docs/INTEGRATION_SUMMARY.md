## 🔧 Настройка

### Переменные окружения (.env.local)

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

# Telegram (обязательно)
TG_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TG_DEFAULT_CHAT_ID=123456789

# Bitrix24 (опционально)
BITRIX_WEBHOOK_URL=https://your-domain.bitrix24.ru/rest/1/webhook-code/
```

### База данных

**Таблицы:**
- `categories` — категории товаров
- `subcategories` — подкатегории
- `products` — товары
- `orders` — заказы
- `order_items` — позиции заказа
- `managers` — менеджеры
- `routing_rules` — правила назначения менеджеров

**Триггеры:**
- `assign_manager_to_order()` — автоматическое назначение менеджеров
- `fn_on_order_items_insert()` — вызов при добавлении позиций

## 🚀 Как использовать

### 1. Настройка Telegram

```bash
# 1. Создайте бота через @BotFather
# 2. Получите токен и добавьте в .env.local
# 3. Получите Chat ID
npm run get-chat-id

# 4. Протестируйте
npm run test-tg
```

### 2. Настройка Bitrix24

1. Создайте входящий вебхук в Bitrix24
2. Добавьте URL в `.env.local`
3. Настройте обработчик на стороне Bitrix24 (опционально)

### 3. Добавление менеджеров

```sql
-- Добавьте менеджеров в Supabase
INSERT INTO public.managers (id, name, tg_chat_id, email, phone)
VALUES (1, 'Иван Иванов', '123456789', 'ivan@company.ru', '+7 999 111-22-33');

-- Настройте правила
INSERT INTO public.routing_rules (category_id, manager_id, priority, is_active)
VALUES ('polystyrene', 1, 1, true);
```

### 4. Тестирование

1. Запустите сайт: `npm run dev`
2. Добавьте товары в корзину
3. Оформите заказ
4. Проверьте уведомления в Telegram

## 📊 Логика работы

### При оформлении заказа:

1. **Создание заказа** в `orders`
2. **Добавление позиций** в `order_items`
3. **Триггер БД** автоматически назначает менеджеров:
   - Главный менеджер по категории с максимальным количеством
   - Менеджер позиции для каждой строки корзины
4. **Асинхронная отправка**:
   - Telegram уведомления главному менеджеру и менеджерам позиций
   - Данные в Bitrix24
5. **Возврат ответа** клиенту (успех/ошибка)
