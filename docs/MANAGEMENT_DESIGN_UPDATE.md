## 🎯 Адаптивность

### Десктоп (≥768px)
- 2 карточки в ряд
- Фото 320px высота
- Крупные шрифты

### Планшет (768px - 1024px)
- 2 карточки в ряд
- Адаптивные размеры

### Мобильные (<768px)
- 1 карточка в ширину
- Фото 280px высота
- Модальное окно на весь экран

## 🎬 Анимации

### Карточки
- **Появление**: fade-in + slide-up
- **Задержка**: 0.1s между карточками
- **Hover**: 
  - Фото увеличивается на 5%
  - Граница меняет цвет на primary
  - Тень усиливается

### Модальное окно
- **Открытие**: zoom-in + fade-in
- **Закрытие**: zoom-out + fade-out
- **Продолжительность**: 200ms

## 🎨 Цветовая схема

- **Фон карточки**: `bg-card`
- **Граница**: `border-border` → `border-primary/50` (hover)
- **Текст имени**: `text-foreground` → `text-primary` (hover)
- **Кнопка**: `bg-primary` с hover эффектом
- **Градиент на фото**: от прозрачного к `black/60`
- **Шапка модального окна**: градиент `from-primary/5 to-primary/10`

## 💡 Особенности реализации

### 1. Одинаковые размеры фото
```tsx
<div className="relative h-80 overflow-hidden">
  <img className="w-full h-full object-cover object-center" />
</div>
```

### 2. Grid layout для 2 колонок
```tsx
<div className="grid grid-cols-1 md:grid-cols-2 gap-8">
```

### 3. Модальное окно почти на весь экран
```tsx
<DialogContent className="max-w-[95vw] max-h-[95vh] w-full h-full">
```

### 4. Прокручиваемая биография
```tsx
<ScrollArea className="flex-1 p-6 md:p-8">
```

## 📦 Используемые компоненты
