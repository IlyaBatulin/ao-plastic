# Модальные окна с биографиями руководителей

## Обзор

При клике на карточку руководителя открывается модальное окно (Dialog) с подробной информацией:
- Фотография руководителя (слева)
- ФИО и должность (справа от фото)
- Полная биография
- Контактная информация (email, телефон) - если указана

## Что было изменено

### 1. ChromaGrid Component (`components/chroma-grid.tsx`)

Добавлен новый проп `onCardClick`:

```typescript
export interface ChromaGridProps {
  // ... существующие пропы
  onCardClick?: (item: ChromaItem, index: number) => void
}
```

**Поведение:**
- Если передан `onCardClick`, он вызывается при клике на карточку
- Если `onCardClick` не передан, но у элемента есть `url`, открывается ссылка (старое поведение)
- Курсор становится pointer, если есть `onCardClick` или `url`

### 2. ManagementClient Component (`app/about/management/management-client.tsx`)

**Добавлено:**
- Состояние `selectedMember` для хранения выбранного руководителя
- Состояние `isDialogOpen` для управления открытием модального окна
- Функция `handleCardClick` для обработки кликов
- Компонент `Dialog` с подробной информацией

**Структура модального окна:**

```tsx
<Dialog>
  <DialogContent>
    <DialogHeader>
      {/* Фото и основная информация */}
      <img /> {/* Фотография 128x128px */}
      <DialogTitle>{ФИО}</DialogTitle>
      <DialogDescription>{Должность}</DialogDescription>
    </DialogHeader>
    
    {/* Биография */}
    <div>
      <h4>Биография</h4>
      <p>{bio}</p>
    </div>
    
    {/* Контакты (опционально) */}
    <div>
      <h4>Контактная информация</h4>
      <a href="mailto:...">Email</a>
      <a href="tel:...">Телефон</a>
    </div>
  </DialogContent>
</Dialog>
```

## Использование

### В коде

```typescript
<ChromaGrid 
  items={items} 
  onCardClick={(item, index) => {
    // Обработка клика
    console.log('Clicked:', item, index)
  }}
/>
```

### Для пользователей

1. Откройте страницу `/about/management`
2. Нажмите на любую карточку руководителя
3. Откроется модальное окно с полной биографией
4. Закройте окно:
   - Кликом на крестик (X) в верхнем правом углу
   - Кликом вне окна
   - Нажатием клавиши `Escape`

## Стили

Модальное окно использует компоненты из `@/components/ui/dialog`:
- Адаптивная ширина (max-w-2xl)
- Максимальная высота с прокруткой (max-h-[90vh])
- Плавная анимация появления/исчезновения
- Затемнение фона (backdrop)

## Доступность

- ✅ Закрытие по клавише Escape
- ✅ Фокус trap (фокус остается внутри модального окна)
- ✅ Закрытие по клику вне окна
- ✅ ARIA-атрибуты для скринридеров
- ✅ Семантические HTML-теги

## Технические детали

### Зависимости

- `@radix-ui/react-dialog` - базовый компонент Dialog
- `lucide-react` - иконка закрытия (X)
- React hooks: `useState` для управления состоянием

### Производительность

- Модальное окно создается один раз и переиспользуется
- Изображения загружаются с `loading="lazy"`
- Анимации оптимизированы через CSS transitions

### Совместимость

- ✅ Десктоп (все браузеры)
- ✅ Планшеты
- ✅ Мобильные устройства
- ✅ Touch events
