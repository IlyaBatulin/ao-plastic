# 📱 Инструкция по настройке Telegram бота для уведомлений о заказах

## 🎯 Цель

Настроить автоматическую отправку уведомлений в Telegram при каждом новом заказе с сайта.

## 📋 Пошаговая инструкция

### Шаг 1: Создание бота через BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя бота (например: "АО Пластик Заказы")
4. Введите username бота (например: `plastic_orders_bot`)
5. Получите токен (формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)
6. Скопируйте токен

### Шаг 2: Добавление токена в .env.local

Создайте или откройте файл `.env.local` в корне проекта:

```env
TG_BOT_TOKEN=ваш_токен_от_BotFather
```

### Шаг 3: Получение Chat ID

**Способ A: Автоматически (рекомендуется)**

```bash
npm run get-chat-id
```

Следуйте инструкциям в консоли:
1. Откройте Telegram
2. Найдите своего бота
3. Отправьте ему любое сообщение (например: `/start`)
4. Вернитесь в консоль и нажмите Enter
5. Скопируйте показанный Chat ID

**Способ B: Вручную**

1. Найдите бота в Telegram
2. Отправьте любое сообщение
3. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
4. Найдите в ответе `"chat":{"id":123456789}`
5. Скопируйте это число

### Шаг 4: Добавление Chat ID в .env.local

```env
TG_DEFAULT_CHAT_ID=123456789
```

### Шаг 5: Тестирование

Проверьте работу бота:

```bash
npm run test-tg
```

Если всё настроено правильно, вы получите тестовое сообщение в Telegram.

### Шаг 6: Проверка в продакшене

1. Запустите сайт: `npm run dev`
2. Добавьте товар в корзину
3. Оформите тестовый заказ
4. Проверьте уведомление в Telegram

   Иван Иванов

🔢 Количество: 10

👨‍💼 Ответственный: Вы

## 🔧 Настройка менеджеров в Supabase

Для назначения разных менеджеров разным категориям добавьте записи в таблицу `managers`:

```sql
-- Добавление менеджера
INSERT INTO public.managers (id, name, tg_chat_id, email, phone)
VALUES (1, 'Иван Иванов', '123456789', 'ivan@company.ru', '+7 999 111-22-33');

INSERT INTO public.managers (id, name, tg_chat_id, email, phone)
VALUES (2, 'Петр Петров', '987654321', 'petr@company.ru', '+7 999 444-55-66');
```

### Правила маршрутизации

```sql
-- Полистирол → менеджер #1
INSERT INTO public.routing_rules (category_id, manager_id, priority, is_active)
VALUES ('polystyrene', 1, 1, true);

-- АБС пластики → менеджер #2
INSERT INTO public.routing_rules (category_id, manager_id, priority, is_active)
VALUES ('abs', 2, 1, true);

-- По умолчанию → менеджер #1
INSERT INTO public.routing_rules (manager_id, priority, is_active)
VALUES (1, 100, true);
```

## ✅ Готово!

Теперь при каждом новом заказе:
- 📦 Главный менеджер получит полную информацию о заказе
- 📋 Каждый менеджер позиции получит уведомление о своей позиции
- 🎯 Уведомления отправляются асинхронно (не блокируют сайт)

## 🐛 Отладка

Если уведомления не приходят, проверьте:

1. **Логи сервера** (консоль где запущен `npm run dev`):
   - `[Telegram] Token configured: true/false`
   - `[Telegram] Default chat: <ваш_chat_id>`

2. **Переменные окружения**:
   ```bash
   # Проверьте что они загружены
   echo $TG_BOT_TOKEN
   ```

3. **Права бота**: Убедитесь что бот не заблокирован в Telegram

4. **Chat ID**: Используйте `npm run test-tg` для проверки

## 📝 Примечания

- ⚠️ **Безопасность**: Никогда не публикуйте `.env.local` в git!
- 🔄 **Асинхронность**: Уведомления отправляются в фоне, ошибки не влияют на сайт
- 🎯 **Множественные менеджеры**: Если в корзине товары из разных категорий, каждый менеджер получит своё уведомление
- 📊 **Логи**: Все интеграции логируются в консоль сервера
