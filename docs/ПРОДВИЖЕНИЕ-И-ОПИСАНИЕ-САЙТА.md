## 1. Краткое резюме

**Сайт** — корпоративный B2B/B2B2C-портал российского химического производителя **АО «Пластик»** (г. Узловая, Тульская область). Это не интернет-магазин в классическом смысле, а **цифровая витрина завода**: каталог полимерного сырья и готовых изделий, корпоративная информация, приём заявок и заказов, разделы для поставщиков и дилеров.

**Главная бизнес-задача сайта:** приводить целевых клиентов (закупщиков, технологов, снабженцев, дилеров) и конвертировать их в **заявки, звонки и коммерческие переговоры**.

**Главная маркетинговая задача:** занять верхние позиции в Яндексе и Google по запросам вроде «АБС-пластик купить», «полистирол ПСВ производитель», «стирол оптом», «АБС пластик Узловая» и смежным B2B-запросам.

**Ключевое конкурентное преимущество для продвижения:** производитель с 1959 года, лидер сегмента АБС в России, сертификация ISO/ГОСТ, прямые поставки без посредников, логистика (200 км от Москвы, М4, ж/д узел Узловая-2).

## 2. Что это за сайт технически

| Параметр | Значение |
|----------|----------|
| **Стек** | Next.js 16, React 19, TypeScript, Tailwind CSS |
| **База данных** | Supabase (каталог, новости, заказы, вакансии, админка) |
| **Хостинг** | Vercel (по конфигурации проекта) |
| **Языки** | Русский (основной) + английский |
| **Домен (из реквизитов)** | `https://www.aoplastic.com` / продакшен: `NEXT_PUBLIC_SITE_URL` |
| **Админ-панель** | Защищённый путь (`ADMIN_PATH`), управление товарами, новостями, заказами |
| **Аналитика** | Vercel Analytics (встроена); Яндекс Метрика — **нужно подключить отдельно** |

### Что сайт умеет «из коробки»

- **Каталог продукции** с категориями, подкатегориями и карточками товаров (характеристики, изображения, RAL-цвета для заказа).
- **Корзина и оформление заявки** — клиент формирует запрос, а не мгновенно оплачивает (типичная модель B2B).
- **Новости** — раздел `/about/news` с SEO-страницами по slug.
- **Формы обратной связи** — контакты, запросы по продуктам, отклики на вакансии.
- **Юридические страницы** — политика конфиденциальности, согласие на обработку ПДн, реквизиты.
- **Cookie-баннер** — согласие на cookies (важно для Метрики и GDPR-подобных требований).
- **SEO-инфраструктура** — sitemap.xml, robots.txt, JSON-LD (Organization, Product, Breadcrumb), Open Graph, canonical URL, верификация Яндекс/Google через env-переменные.
- **Защита от ботов** — middleware пропускает поисковых роботов (Yandexbot, Googlebot) даже при SITE_PASSWORD.
- **Двуязычность** — переключение RU/EN для экспортных клиентов.

### Чего на сайте пока нет (и что стоит добавить для продвижения)

- **Яндекс Метрика** — счётчик не подключён в коде (только заготовка для верификации в Вебмастере).
- **Яндекс Бизнес / Google Business Profile** — внешние сервисы, настраиваются отдельно.
- **Блог с регулярными статьями** — есть новости и публикации, но нет отдельного SEO-блога с длинными экспертными материалами.
- **Кейсы клиентов** — раздел «наши проекты / отрасли применения» усилил бы конверсию.
- **Сравнительные таблицы марок** — полезны для технологов (можно вынести в контент Дзена и на сайт).

## 9. Стратегия продвижения: общая логика

### Принцип для B2B-химии

Продвижение АО «Пластик» — это **не массовый B2C-трафик**, а **точечное привлечение профессионалов** с высоким LTV (пожизненной ценностью клиента). Один завод-переработчик может закупать тонны ежемесячно годами.

### Приоритет каналов (от высокого к низкому ROI)

| № | Канал | Почему |
|---|-------|--------|
| 1 | **SEO (Яндекс + Google)** | Долгосрочный поток целевых B2B-запросов |
| 2 | **Яндекс Директ** | Быстрый трафик по коммерческим запросам |
| 3 | **Яндекс Дзен (статьи)** | Экспертность + ссылки + прогрев аудитории |
| 4 | **Отраслевые каталоги** | Plastinfo, Химия и жизнь, отраслевые справочники |
| 5 | **Яндекс Метрика + Вебмастер** | Без аналитики невозможно оптимизировать |
| 6 | **Выставки + PR** | Plastex, КИП, отраслевые СМИ |
| 7 | **Дилерская сеть** | Масштабирование без роста штата продаж |
| 8 | **VK / Telegram** | Доверие, новости, работа с дилерами |

### Воронка по этапам зрелости

**Месяц 1–2:** Техническая база (Метрика, Вебмастер, Search Console, цели, карточки организаций).  
**Месяц 2–4:** SEO-оптимизация каталога + первые 10–15 статей в Дзен.  
**Месяц 3–6:** Директ по горячим запросам + отраслевые каталоги.  
**Месяц 6–12:** Масштабирование контента, кейсы, выставки, дилерский портал.

## 10. Поисковое продвижение (SEO)

### 10.1. Техническое SEO (сделать в первую неделю)

1. Зарегистрировать сайт в **[Яндекс Вебмастер](https://webmaster.yandex.ru/)** и **[Google Search Console](https://search.google.com/search-console)**.
2. Указать `NEXT_PUBLIC_SITE_URL` на боевой домен (без www/www — единообразно).
3. Отправить `sitemap.xml` в обе системы.
4. Проверить индексацию ключевых страниц: `site:oaplastic.ru абс пластик`.
5. Убедиться, что `SITE_PASSWORD` **отключён** на продакшене (или роботы пропускаются — уже реализовано).
6. Настроить **301-редирект** с зеркал (http→https, www↔без www).

### 10.2. On-page SEO (страницы каталога)

Для каждой категории и марки:

- **Title:** `{Марка/категория} — купить от производителя | АО «Пластик»`
- **Description:** 150–160 символов с УТП: производитель, Узловая, сертификат, доставка по РФ.
- **H1:** точное название продукта.
- **Текст на странице:** 300–800 слов — применение, преимущества, ТУ/ГОСТ, логистика, CTA.
- **Внутренние ссылки:** из статьи Дзен → на карточку товара; между смежными марками.
- **Изображения:** alt-теги «АБС Л-121 гранулы АО Пластик», WebP, сжатие.

### 10.3. Контентное SEO

Создать раздел **«База знаний»** или расширить `/about/news`:

- «Как выбрать марку АБС для литья под давлением»
- «ПСВ-С vs ПСВ-Л: в чём разница»
- «Требования ГОСТ к полистиролу вспенивающемуся»
- «Импортозамещение АБС-пластиков в автопроме»

Каждая статья = целевой информационный запрос + ссылка на коммерческую страницу.

### 10.4. Локальное SEO

- **Яндекс Бизнес:** карточка завода (Узловая) + офис (Москва).
- **2ГИС:** актуальные контакты, фото производства.
- **Google Business Profile** (если актуально для иностранных партнёров).

### 10.5. Ссылочное продвижение (аккуратно)

Для B2B-химии качество важнее количества:

- Отраслевые порталы (статьи, упоминания).
- Партнёры-дилеры (ссылка с их сайта).
- Публикации из раздела `/about/publications` — продолжать наращивать.
- **Не покупать** дешёвые ссылки с сомнительных бирж — риск фильтров Яндекса.

## 11. Контент-маркетинг и Яндекс Дзен

### Почему Дзен подходит именно вам

- Аудитория 25–55 лет, в т.ч. предприниматели и специалисты.

- Можно вставлять ссылки на сайт (в рамках правил платформы).
- Тематика «промышленность, химия, производство» — ниша с меньшей конкуренцией, чем у lifestyle-блогов.

2. Оформить: логотип, обложка завода, описание со ссылкой на сайт.
3. Пройти модерацию (указывать реальную компанию — плюс к доверию).
4. Публиковать **2–4 статьи в месяц** минимум, лучше 1 в неделю.

### Форматы статей, которые работают

| Формат | Пример | Цель |
|--------|--------|------|
| **Обучающий** | «5 ошибок при выборе АБС для литья» | Доверие, сохранения |

### Структура идеальной статьи для Дзена

```

3. Подзаголовки H2/H3 каждые 300–400 слов
4. Таблица или список (алгоритм любит структуру)
5. 1–2 фото производства / продукции (уникальные!)
6. Мягкий CTA: «Подробные характеристики — на сайте ao...»

```

## 12. Яндекс Метрика и аналитика

### Почему это критично

Без Метрики вы не знаете:
- откуда приходят закупщики;
- какие страницы каталога смотрят перед заявкой;
- на каком шаге уходят;
- какие ключевые слова из Директа окупаются.

### Пошаговое подключение

1. Создать счётчик на [metrika.yandex.ru](https://metrika.yandex.ru/).
2. Получить номер счётчика (например, `12345678`).
3. Добавить в проект (рекомендуемый способ для Next.js):

```tsx
// components/yandex-metrika.tsx
"use client"
import Script from "next/script"
import { usePathname, useSearchParams } from "next/navigation"
import { useEffect } from "react"

const COUNTER_ID = process.env.NEXT_PUBLIC_YANDEX_METRIKA_ID

export function YandexMetrika() {
  const pathname = usePathname()
  const searchParams = useSearchParams()

  useEffect(() => {
    if (!COUNTER_ID || typeof window === "undefined") return
    const url = pathname + (searchParams?.toString() ? `?${searchParams}` : "")
    // @ts-expect-error ym injected by script
    window.ym?.(Number(COUNTER_ID), "hit", url)
  }, [pathname, searchParams])

  if (!COUNTER_ID) return null

  return (
    <Script id="yandex-metrika" strategy="afterInteractive">
      {`
        (function(m,e,t,r,i,k,a){m[i]=m[i]||function(){(m[i].a=m[i].a||[]).push(arguments)};
        m[i].l=1*new Date();k=e.createElement(t),a=e.getElementsByTagName(t)[0],k.async=1,k.src=r,a.parentNode.insertBefore(k,a)})
        (window, document, "script", "https://mc.yandex.ru/metrika/tag.js", "ym");
        ym(${COUNTER_ID}, "init", {
          clickmap:true,
          trackLinks:true,
          accurateTrackBounce:true,
          webvisor:true,
          ecommerce:"dataLayer"
        });
      `}
    </Script>
  )
}
```

4. Подключить в `app/layout.tsx` **после согласия на cookies** (у вас уже есть `CookieConsentBanner`).
5. В `.env`:
   ```env
   NEXT_PUBLIC_YANDEX_METRIKA_ID=12345678
   ```

### Цели в Метрике (настроить обязательно)

| Цель | Условие | Бизнес-смысл |
|------|---------|--------------|
| **Заявка отправлена** | URL содержит `/cart` + событие submit ИЛИ success-page | Главная конверсия |
| **Клик по телефону** | JavaScript-событие на `tel:` ссылках | Горячий лид |
| **Клик по email** | Событие на `mailto:` | B2B-лид |
| **Добавление в корзину** | JS-событие из cart-context | Намерение купить |
| **Просмотр карточки товара** | URL `/products/*/*/*` | Вовлечённость |
| **Скачивание сертификата** | Клик на PDF в /certificates | Тендерный клиент |
| **Заполнение формы контактов** | Отправка формы на /contacts | Лид |

### Связка Метрика + Директ + Дзен

- В Директе включить **автоматические цели** из Метрики.
- В Дзене (при наличии промо) отслеживать UTM-метки: `?utm_source=dzen&utm_medium=article&utm_campaign=abs-guide`.
- Еженедельно смотреть **Вебвизор** — как реальные закупщики ходят по каталогу.

### Дополнительно: Vercel Analytics

Уже подключена в `package.json` (`@vercel/analytics`). Использовать для технических метрик (скорость, Web Vitals), но **бизнес-решения принимать по Метрике** — она понимает российский трафик лучше.

- Визиты и источники (Метрика)
- Количество заявок / звонков
- CPL по Директу
- Позиции по 10 ключевым запросам

### Ежемесячно

| KPI | Как измерять | Ориентир (6 мес) |
|-----|--------------|------------------|
| Органический трафик | Метрика | +50% к базе |
| Заявки с сайта | Цели Метрики | 30–80/мес |
| Стоимость лида | Директ / заявки | < 5 000 ₽ |
| Индексация | Вебмастер | 95%+ страниц каталога |
| Просмотры Дзен | Статистика Дзена | 10 000+/мес |
| Конверсия каталога | Заявки / визиты на /products | 1–3% |

### Связь с продажами

Маркетинг отчитывается не по «лайкам», а по **MQL → SQL → сделка**. Настройте в CRM (Битрикс24, amoCRM) поля «источник» и UTM.

## 23. Риски и типичные ошибки

| Ошибка | Последствие | Решение |
|--------|-------------|---------|
| Гнаться за трафиком, а не за лидами | Бюджет впустую | Цели на заявки и звонки |
| Вести рекламу на главную | Низкая конверсия | Посадочные — категории каталога |
| Покупать дешёвые ссылки | Фильтр Яндекса | Только отраслевые площадки |
| Игнорировать Метрику | Невозможно оптимизировать | Подключить до Директа |
| Копипаст чужих статей в Дзен | Бан канала | Уникальный контент от технологов |
| Не обновлять каталог | Отток SEO | Регулярные новости и товары |
| SITE_PASSWORD на проде | Пользователи не видят сайт | Отключить |
| Один канал (только Директ) | Высокий CPL | SEO + Дзен + каталоги |
