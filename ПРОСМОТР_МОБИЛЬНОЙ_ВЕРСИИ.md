# 📱 Как посмотреть мобильную версию сайта в Cursor

## 🚀 Быстрый способ

### 1. Запустите dev-сервер (если еще не запущен)
```bash
npm run dev
```

### 2. Откройте браузер
Перейдите по адресу: **http://localhost:3000**

### 3. Откройте инструменты разработчика

**Chrome/Edge:**
- Нажмите `F12` или `Ctrl+Shift+I` (Windows) / `Cmd+Option+I` (Mac)
- Или кликните правой кнопкой → "Проверить элемент"

**Firefox:**
- Нажмите `F12` или `Ctrl+Shift+I` (Windows) / `Cmd+Option+I` (Mac)

### 4. Включите режим эмуляции устройства

**Chrome/Edge:**
- Нажмите `Ctrl+Shift+M` (Windows) / `Cmd+Shift+M` (Mac)
- Или нажмите на иконку 📱 "Toggle device toolbar" в верхней панели DevTools

**Firefox:**
- Нажмите `Ctrl+Shift+M` (Windows) / `Cmd+Shift+M` (Mac)
- Или нажмите на иконку 📱 "Responsive Design Mode"

### 5. Выберите устройство

В верхней панели выберите из списка:
- **iPhone 12/13/14** (390x844)
- **iPhone SE** (375x667)
- **Samsung Galaxy S20** (360x800)
- **iPad** (768x1024)
- Или создайте свой размер: **"Edit..."** → введите нужные размеры

### 6. Полезные функции

- **Поворот экрана**: Кнопка поворота в панели инструментов
- **Сеть**: Имитация медленного интернета (3G, 4G)
- **Touch**: Эмуляция сенсорных жестов
- **Размеры**: Изменение ширины/высоты вручную

## 🎯 Горячие клавиши

| Действие | Windows | Mac |
|----------|---------|-----|
| Открыть DevTools | `F12` или `Ctrl+Shift+I` | `Cmd+Option+I` |
| Режим устройства | `Ctrl+Shift+M` | `Cmd+Shift+M` |
| Закрыть DevTools | `F12` или `Esc` | `Esc` |

## 📐 Популярные разрешения для тестирования

- **Мобильный (маленький)**: 375x667 (iPhone SE)
- **Мобильный (средний)**: 390x844 (iPhone 12/13)
- **Мобильный (большой)**: 414x896 (iPhone 11 Pro Max)
- **Планшет**: 768x1024 (iPad)
- **Планшет (горизонтально)**: 1024x768

## 💡 Совет

Сохраните часто используемые размеры:
1. В Chrome DevTools нажмите "Edit..."
2. Добавьте свой размер
3. Он сохранится в списке устройств

## 🔄 Обновление страницы

После изменения кода:
- Страница обновится автоматически (Hot Reload)
- Или нажмите `Ctrl+R` / `Cmd+R` для ручного обновления

---

**Примечание:** В Cursor нет встроенной функции для изменения разрешения, но браузер с DevTools — это стандартный и самый удобный способ для тестирования мобильной версии.
