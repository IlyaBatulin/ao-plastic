# 📋 Список необходимого для запуска проекта

## ✅ Что уже установлено:
- ✅ Git (версия 2.52.0)

## ❌ Что нужно установить:

### 1. Node.js (обязательно)
- **Скачать:** https://nodejs.org/
- **Рекомендуется:** LTS версия (Long Term Support)
- **Проверка установки:** После установки откройте новый терминал и выполните:
  ```bash
  node --version
  npm --version
  ```
- **Важно:** При установке выберите опцию "Add to PATH"

### 2. Создать файл `.env.local` (обязательно)
После установки Node.js создайте файл `.env.local` в корне проекта со следующим содержимым:

```env
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here

# Telegram Bot Configuration (можно оставить пустым для начала)
TG_BOT_TOKEN=
TG_DEFAULT_CHAT_ID=

# Bitrix24 Webhook (опционально)
BITRIX_WEBHOOK_URL=
BITRIX_DEFAULT_ASSIGNED_ID=1
```

**Где взять данные:**
- **Supabase:** Создайте проект на https://supabase.com и скопируйте ключи из настроек
- **Telegram:** Создайте бота через @BotFather в Telegram (можно настроить позже)
- **Bitrix24:** Настройте вебхук в Bitrix24 (опционально)

## 📝 Порядок действий:

1. **Установите Node.js** с https://nodejs.org/
2. **Перезапустите Cursor** (или откройте новый терминал)
3. **Создайте файл `.env.local`** в корне проекта (можно скопировать шаблон выше)
4. **Установите зависимости:**
   ```bash
   npm install
   ```
5. **Запустите dev-сервер:**
   ```bash
   npm run dev
   ```
6. **Откройте браузер:** http://localhost:3000

## ⚠️ Важные замечания:

- Без Node.js проект не запустится
- Без `.env.local` некоторые функции (Supabase, Telegram) не будут работать
- Для базового просмотра сайта можно запустить и без полной настройки `.env.local`, но функционал будет ограничен
